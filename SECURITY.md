# Сообщения об уязвимостях

FileX находится в разработке. Поддерживается текущая ветка `main`; принятых production releases пока нет. Границы проверки и блокеры выпуска описаны в [wiki/current-state.md](wiki/current-state.md). Зелёный CI не означает завершённую независимую security-приёмку.

Отправляйте уязвимости через [приватный GitHub Security Advisory](https://github.com/elnemir/p2p-files/security/advisories/new). Если форма недоступна, используйте приватный канал, уже согласованный с владельцем; не переносите детали в публичный issue.

Укажите commit/version, компонент, условия, минимальный сценарий на синтетических данных, ожидаемое и фактическое поведение, влияние. Не включайте рабочие секреты, payload пользователей, raw access links, cookies, PIN, KEK или дамп базы. Для примеров используйте `example.test` и очищенные логи.

Проверяйте воспроизведение на собственном изолированном стенде. Наличие публичного исходного кода не даёт разрешения тестировать чужие экземпляры. Срок ответа/SLA и вознаграждение не установлены. Порядок triage, исправления и согласованного раскрытия определяется владельцем по конкретному сообщению.

Для сопровождающего: [модель угроз](wiki/threat-model.md), [incident response](wiki/incident-response.md), [критерии выпуска](wiki/release-checklist.md), [настройка репозитория](wiki/repository-governance.md).
