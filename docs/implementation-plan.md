# План реализации

Канонические фазы 0–7 и условия закрытия: [roadmap](../wiki/roadmap.md). Текущее поручение расширено до **этапов 1–5**: platform/auth → transfers → ZIP/crypto → communications → reports/artifacts. Фаза 0 подготовила contracts/design baseline. Реальное исполнение и оставшиеся действия: [session](../wiki/session.md).

После 1–5 идут backup/restore/reconciliation/operations (6), затем release security/DR/performance/browser/a11y/SBOM (7). Все 32 MUST сохранены. Прогресс и evidence учитываются по [traceability](test-matrix.md), а не по наличию каркасов. Production deploy выполняется только по отдельной явной команде.
